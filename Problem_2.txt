## How to Run

1. Navigate to solutions/problem_2/ and launch Jupyter:
     jupyter notebook RunTaxiTrips.ipynb
2. Run all cells in order top-to-bottom (Kernel → Restart & Run All).

Required data files (relative to solutions/problem_2/):
  ../../data/problem_2/trip_data-part*.csv
  ../../data/problem_2/nyc-borough-boundaries-polygon.geojson.json

Note: The notebook applies a day-13 filter before caching to keep memory usage
manageable on a local machine (all 4 CSV parts together exceed local JVM heap when
fully cached). To obtain results over the entire recorded period for (a) and (b),
remove the `.filter(lambda x: x[1].pickupTime.day == 13)` line in cell-04-load
and run on the IRIS HPC cluster.

Clean trips loaded (day-13 sample, duration 0–3 h, valid coordinates): 433,927
