HOW TO RUN
----------
1. Upload the dataset files to the IRIS cluster:
   - nodes.csv, edges.csv, hero-edge.csv → ./data/problem_1/kaggle-marvel-universe

2. Submit the notebook as a Spark job on IRIS:
   spark-submit --packages graphframes:graphframes:0.8.2-spark3.1-s_2.12 \
                --master yarn \
                Exercise1_Marvel_GraphAnalysis.ipynb

   Or run interactively via Jupyter on the cluster with:
   --config spark.jars.packages=graphframes:graphframes:0.8.2-spark3.1-s_2.12

3. sbatch run_spark.sh
